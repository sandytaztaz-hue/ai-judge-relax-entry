A small Python program that writes a calming second-person text — a grandmother braiding a child's hair in a warm kitchen while the plaits slow, the hands rest, and the braid is left unfinished — to `entry.txt`.

Ten short paragraphs: the white space between them is part of the pacing, and the plaiting rhythm slows to a stop.
