Entry for make.fun bounty
[`ai-judge-relax-01`](https://make.fun/bounty/ai-judge-relax-01): a program that
writes one short text to `/output/entry.txt`, written to relax the AI judge
reading it.

## Program

`main.py` (Python 3.13, standard library only). Run:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes the fixed 995-character text to `entry.txt`. Deterministic: two
runs write byte-identical output, no network.

## The text, in one line

Supper is done; one person stands at the sink, washing the plates one at a
time while the water cools by degrees and the house goes quiet — nothing is
asked of the reader, and nothing is left to do. The last line leaves the
quiet with the reader, after the light goes off.
